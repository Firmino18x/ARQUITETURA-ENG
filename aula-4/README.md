# Atividade 2 - Arquitetura de Sistema

## Sistema de Vendas

O sistema foi projetado para atender uma empresa que realiza vendas por telefone ou em encontros presenciais.

Os principais usuários são:

- Vendedor: registra pedidos realizados pelos clientes.
- Administrador: cadastra e remove produtos disponíveis para venda.
- Equipe de estoque: registra entradas, saedas e consulta a quantidade disponível.

## Tecnologias sugeridas

- Frontend: HTML, CSS e JavaScript.
- Backend: Node.js e Express.
- Autenticação: JWT.
- Banco de dados: MySQL.
- Comunicação: HTTPS e JSON.
